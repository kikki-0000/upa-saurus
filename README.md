# upa-saurus
マイクロビットコンテスト2025に応募した作品『ウパザウルス』のソースコード<br>
メイクコードで作成できる。

## 各ファイルの説明
main_unit: LEDに繋いで、ゲームの進行を担うマイクロビットのコード<br>
left_unit: パンチゲームで左手につけるマイクロビットのコード<br>
right_unit: パンチゲームで右手につけるマイクロビットのコード<br>
left_unit2: 仲良しゲームで左手につけるマイクロビットのコード<br>
right_unit2: 仲良しゲームで右手につけるマイクロビットのコード<br>

## 作り方
ーー目次ーーー<br>
1. 材料を用意する
2. マイクロビットを動かせる状態にする
3. main_unitにコードを書き込む
4. 子機に機械学習したモデルを使ったコードを書き込む
5. ウパザウルスを作る
6. 完成

### 1. 材料を用意する
- 巨大な浮き輪
- LEDテープ（浮き輪の大きさに合わせて買う）
- マイクロビット5台
- マイクロビットの電池ボックス
- LEDの電池ボックス
- マイクロビットのバングルモジュール
- それぞれの電池（単三or単四　and コイン電池）
- ハンダ
- ドライバー
