# upa-saurus
マイクロビットコンテスト2025に応募した作品『ウパザウルス』のソースコード<br>
メイクコードで作成できる。

## 各ファイルの説明
main_unit: LEDに繋いで、ゲームの進行を担うマイクロビットのコード<br>
left_unit: パンチゲームで左手につけるマイクロビットのコード<br>
right_unit: パンチゲームで右手につけるマイクロビットのコード<br>
left_unit2: 仲良しゲームで左手につけるマイクロビットのコード<br>
right_unit2: 仲良しゲームで右手につけるマイクロビットのコード<br>

## 作り方
1. 材料を用意する
2. マイクロビットを動かせる状態にする
3. main_unitにコードを書き込む
4. 子機に機械学習したモデルを使ったコードを書き込む
5. ウパザウルスを作る（）
6. 完成

### 1. 材料を用意する
- 巨大な浮き輪
- LEDテープ（浮き輪の大きさに合わせて買う）
- マイクロビット5台
- マイクロビットの電池ボックス
- LEDの電池ボックス
- マイクロビットのバングルモジュール
- それぞれの電池（単三or単四　and コイン電池）
- ハンダ
- ドライバー

### 2. マイクロビットを動かせる状態にする
それぞれ4つバングルモジュールにコイン電池をいれ、マイクロビットに装着します。
main_unitのマイクロビットに電池ボックスを繋ぎ、LEDにも電池ボックスの導線を繋げます。
（6VくらいないとLEDの光が弱いので、そこは個人で調整してください）
main_unitのマイクロビットとLEDテープを以下のように繋げます。
DIN――0
GND――GND

### 3. main_unitにコードを書き込む
main_unitファイルのコードをメイクコードにコピペして、main_unitのマイクロビットに書き込みます。

### 4. 子機に機械学習したモデルを使ったコードを書き込む
CreateAIを開き自分のパンチもしくはなでなでを機械学習する
モデルをつかって、それぞれのユニットにコードを書き込む

### 5. ウパザウルスを作る
浮き輪を膨らませて、LEDテープを巻く

### 6. 完成
完成したら、遊んでみよう。

## 遊び方
ーーパンチングゲームーーー<br>
まず両腕にマイクロビットをつけます。
つけたら、浮き輪に座ってメインユニットのマイクロビットのAボタンを押します。
そのあとはLEDが光ったところをパンチするだけ。
メインユニットにHPが表示されるから、HPを0にするまで、LEDが光ったところを確実にパンチしよう。
どういうパンチがヒットするのか考えてパンチしてみよう。
HPが0になると音楽が流れLEDテープが虹色に光ります。
追加ルール：パンチがヒットせず、10秒ほど経過するとゲームオーバーになります。

ーー仲良しゲームーーー<br>
まず両手にマイクロビットをつけます。
つけたら、浮き輪に座ってメインユニットのマイクロビットのBボタンを押します。
そのあとは、LEDが光ったところをなでるだけ。
どういう撫で方がウパザウルスが好きなのか考えて仲良くなろう。
親密度が100になると音楽が流れ、LEDが虹色に光ります。
